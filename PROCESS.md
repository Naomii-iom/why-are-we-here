# Process

## Tools and Uses

I used ChatGPT during this assignment for brainstorming, planning the structure, drafting English sentences, and editing the essay. I also watched Dylan Beattie’s *The Art of Code* and used it to think about programming as a creative medium.

## What I Kept

I kept the idea that learning programming is not mainly about writing code faster than AI. It is about understanding enough to judge AI-generated code, specify a design idea more clearly, and work across different projects.

This idea was useful because it connected directly to my own experience with an interactive-screen project in a subway passage. In that project, I used AI to generate code, but when it failed, I could not find the small numerical error because I did not understand the logic.

I also kept the connection between Beattie’s talk and design. His examples of generative art and live coding helped me see code as part of the material of an interactive experience, rather than only an invisible technical tool.

## What I Rejected

I rejected an earlier AI-generated opening that discussed AI and technological change in a very general way. It sounded plausible, but it could have applied to almost any course or student. It did not explain why learning programming matters in my own design practice.

Instead, I centred the essay on the subway-screen project. This made the argument more specific and helped me explain the difference between receiving code from AI and actually understanding it.
